# iPhone（iOS）说明

**能做到。** iOS 上用 **Shadowrocket（小火箭）** 可以配出和 Mac 等价的效果——只有 Claude 相关流量走美国静态住宅 IP，其余走机场。作者本人的 iPhone 就是这么配的，长期在用。

**但具体步骤暂时不写在这里**：iOS 侧和 Mac 完全是两套操作（都在 App 界面里点，还跟版本有关），没整理成能照抄的手册之前写出来容易误导。**要在手机上配就直接找分享人问**——他配过。

⚠️ 一条必须记住的红线：**Mac 上不要装 Shadowrocket**。Mac 版会和 Clash Verge 抢系统路由，轻则规则失效、重则整机断网（排障手册第 1 条就是这个坑）。**手机版没有这个问题**——手机用小火箭、Mac 用 Clash Verge，两边同时用互不干扰。
